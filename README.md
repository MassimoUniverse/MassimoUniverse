## Привет! 👋

Делаю простые инструменты, чтобы заблокированные сайты снова открывались —
без VPN, без настройки руками, в один клик.

### 🛡️ [Пропуск](https://github.com/MassimoUniverse/propusk)

Обход блокировок YouTube, Discord, X и Instagram на **Mac**. Приложение в строке
меню: ставится за минуту и само подбирает способ обхода под вашего провайдера.
IP не меняется, скорость не падает.
